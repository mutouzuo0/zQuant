# g07 最低佣金触发 — 手算期望值表

> 防自证（方案 §1.4/§2.4）：下表由人工独立计算。测试 import `g07.json` 断言。

## 场景

- 佣金额 = max(commission_min=5.0, 0.0001 × amount)；印花税买入 0。
- **小额**：100 股 × 5.0 = **500 元** 成交额（初始资金 100,000）；
- **对照大额**：20,000 股 × 10.0 = **200,000 元** 成交额（初始资金 1,000,000）。

## 逐条手算表

| 科目 | 小额（500 元） | 大额（200,000 元） |
|---|---|---|
| commission | max(5, 0.05) = **5.00** | 0.0001×200,000 = **20.00** |
| stamp_tax | 0.00 | 0.00 |
| transfer_fee | 0.00 | 0.00 |
| total | **5.00** | **20.00** |
| 成交后现金 | 100,000 − 500 − 5 = **99,495.00** | 1,000,000 − 200,000 − 20 = **799,980.00** |
| 持仓市值 | 500.00 | 200,000.00 |
| 权益 | 99,995.00 | 999,980.00 |
| NAV | **0.99995** | **0.99998** |

临界检查：500 元 → 0.05 < min=5 → 佣金被下限兜底到 5.0；200,000 元 → 20.0 ≥ 5 → 比例段生效。
